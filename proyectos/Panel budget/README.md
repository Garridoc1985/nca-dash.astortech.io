# Panel budget

Esta carpeta contiene todos los resultados generados para el proyecto de Panel Budget Liquidez.

## Estructura

- `propuesta_sistema_budget_liquidez.md` — propuesta en formato Markdown.
- `propuesta_sistema_budget_liquidez.docx` — versión Word generada.
- `generar_propuesta_docx.py` — script que convierte el Markdown en DOCX.
- `frontend/` — carpeta con los archivos del frontend generado.

## Instalación

```bash
pip install -r requirements.txt
```

## Regla de trabajo

A partir de ahora, todos los resultados y archivos relacionados con este proyecto se guardarán dentro de esta carpeta.

Para regenerar el documento DOCX desde el Markdown:

```bash
cd "c:\Users\Usuario\Desktop\espacio-de-trabajo-claude\Panel budget"
python generar_propuesta_docx.py
```
